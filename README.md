# Google Calendar App

Google Calendar as a Windows desktop app: a lightweight Electron wrapper around the normal Google Calendar in the browser, with local session storage so your login and window state are preserved.

## Download

[Google Calendar App Setup 1.0.0.exe]()

## Quick Info

- Uses the normal Google Calendar as a desktop app on Windows
- Saves the session locally so you stay signed in
- Remembers window size and position
- Can be installed directly through the installer
